# Empirical Research in Finance — Summer 2026

Course repository for the *Empirical Research in Finance* seminar at
Humboldt-Universität zu Berlin, Summer Semester 2026.

## Repository structure

- `code/` — reproducible analysis code
- `data/raw/` — original input datasets
- `results/` — generated tables, figures, and model outputs
- `paper/group/` — group research report
- `paper/individual/` — individual research proposal

## Reproducibility

Original input files remain unchanged in `data/raw/`. Generated analytical
outputs should be written to `results/`.
